Section 2 – Probability of each token → perplexity

Model output will appear here once you calculate perplexity for a sentence.
# Token Probability P 1/P (Surprisal)
Step 1: Multiply 1/P Values
Product = ∏ (1 / P)
Step 2: Number of Tokens
N = sequence length
Step 3: Perplexity
Perplexity = (Product)1/N
--
Computed stably via exp(average of −ln P).
